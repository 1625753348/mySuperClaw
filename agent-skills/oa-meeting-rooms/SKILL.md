# 查询 OA 会议室

1. 查看 `oa_meeting_room_list` 的参数契约后查询 OA。
2. 如果用户给出人数，筛选容量不少于该人数的会议室。保留会议室名称、楼层和容量。
3. 使用 [输出模板](references/format.md) 组织结果。
4. 如果没有满足条件的会议室，说明返回的记录里没有匹配项。

查询结果表示会议室配置和容量。具体时段能否预约需要另行查询。
